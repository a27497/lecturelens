# 桌面学习回顾

B1 工作区保留看课、Tutor、显式练习、作答及反馈的原有关系，并提供以下读取入口：

- **练习结果**：解释与练习中的“练习结果”按当前 Run 的每道题展示持久化作答版本、对应反馈、核对记录和最近反馈执行状态。未保存草稿不计入结果。可返回本题、答案版本、对应反馈及来源；学习记录可切换其他 Session/Run。没有自动评分或掌握率。
- **历史问答**：Tutor 打开或刷新时读取本课程本人已保存问答，选择记录可查看旧回答并继续明确提问。未提交问题不跨刷新恢复。历史问答的原学习范围未持久化，不将当前范围倒填为历史范围。
- **学习资料**：桌面主导航直接进入已保存摘要、重点、术语和章节。旧资料没有 Evidence 关联时只显示文本；章节时间入口是普通定位，不标记为可信引用。章节生成仍需明确操作。

## 读取契约

`GET /api/tasks/{taskId}/qa/history?limit=20&before={recordId}` 返回 `items` 和 `nextCursor`。数量范围1–50，按ID倒序，创建时间以UTC Instant（Z）返回；客户端每轮最多载入最近100条，可刷新回最新。每次按当前用户及未删除课程核验，记录查询同时限定用户/课程，读后再次核验权限与revision。只返回问题、回答、状态、时间及当前有效的来源，排除模型路由、usage、调用记录和执行快照。失败问答不返回原始错误。

来源仅从已经存在的当前 `course_evidence` 校验，历史读取不生成快照、索引、Run或模型调用。旧revision、缺失或不可检索来源不作为可信引用；点击时仍经过工作区原有版本围栏。与任何网络读取相同，响应到达后权限变化由下一次读取/来源操作重新校验。

Study `READ` 增加 `practice_results`，在现有用户/课程/revision/Session/Run 授权内逐题读取最新attempt、优先对应其版本的已完成反馈（否则保留旧反馈）、最近反馈执行状态及该反馈的最新核对记录。它不依赖最近20条反馈窗口推断“无反馈”，不揭示参考答案，不写学习状态。PostgreSQL仍为权威，未新增数据表或执行引擎。

## 验证

前端：`npm ci && npm run test:unit && npm run build && npm audit --audit-level=high`。
后端：`./mvnw test`，MySQL机制测试需独立测试数据库。
Python：`uv run ruff check src tests && uv run ruff format --check src tests && uv run pytest -q`，`AGENT_TEST_DATABASE_URL`必须指向独立PostgreSQL测试库；跳过数据库不算完整通过。

浏览器以1440×900、1280×800验收真实Vue→Java→Python→独立MySQL/PostgreSQL，使用合成材料、Mock模型和离线embedding。它证明交互及持久化机制，不证明真实模型教学质量。移动端保留现有响应式，不在本轮专项验收范围。详细候选身份、原始日志、截图和访问方法随PR交付，不能以HTTP夹具代替真实服务结果。

## 候选身份

历史冻结候选 `e34d8c596d74d4320ce6a224359190374520e4d3` 的56模块清单原样保存在 `acceptance_agent_manifest.json`，其每个模块可由该Git提交独立重建。历史校验同时检查清单摘要、模块集合和逐文件哈希；P3源码及历史/开发混合版本会被拒绝。旧评测与费用记录继续归属原候选，不能用于证明本次读取能力或模型质量。

P3读取候选另存 `development_agent_manifest.json`（57模块），身份为 `p3-read-review-480fc58639fd4a59`；实际身份常量以 `acceptance_cost.DEVELOPMENT_AGENT` 为准。独立开发验证检查固定清单摘要、精确模块集合和逐文件哈希。原有55模块不变，仅 `study/store.py` 的结果读取和新增 `study/results.py` 属于读取扩展。修改清单和测试预期不能让该扩展通过历史入口。

离线费用命令明确报告历史身份与独立开发身份，费用策略只接受独立开发候选及确定性 Fake 模式；真实Provider模式和授权标识仍被拒绝。预算、超时、未知结果停止及不可退款规则保持原有硬限。此入口不授予真实Provider调用权限。

## 显式刷新与草稿

Tutor刷新重新核验当前选中记录；记录不在当前页或读取失败时保留回答文字并清除可信来源。刷新期间及失败后的旧列表也不恢复失效引用。迟到分页不能覆盖新问题完成后的列表；自动恢复优先选择本页最近成功回答，FAILED记录仍可显式查看。

练习结果读取同步父组件的最新已保存作答。无草稿时表单使用新版本；有草稿时保留本地文字并提示服务器版本变化。重新打开同一反馈会重新读取核对记录，保留未保存文字和版本冲突保护。新反馈执行期间，旧成功反馈通过只读预览查看；新Run继续轮询和取消，预览不改变核对草稿。

Tutor来源按当前课程、用户、revision和Evidence ID按页批量读取，最多50条×8个引用，逐项核验payload、身份、可检索性及revision，读后再检查课程权属与版本。最多一次Evidence批量查询，缺失、重复或无效来源不能作为可信引用。读取不生成快照、Run或模型调用。

## 从保存的反馈继续学习

解释与练习顶部显示“继续本次练习”，依据当前练习已保存的作答、反馈归属与核对记录，提示待核对、旧版反馈或尚未作答的题目。进入前再次只读核对；记录发生变化时先更新提示。保存与核对不是成绩，也不表示已经订正。

“刷新学习进度”可读取其他标签页的新版本；本页未保存文字保留，并提示服务器版本变化。刷新或离开页面仍会丢弃未保存输入。阅读、恢复、刷新及来源定位不创建Run或模型请求。此入口只覆盖当前练习，不跨会话安排任务。
