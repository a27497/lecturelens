# Lightweight course Tutor (experimental, Mock only)

The existing course workspace's **Tutor 对话** supports a saved, bounded teaching dialogue. Python owns context, retrieval orchestration, generation and PostgreSQL state; Java remains the authenticated gateway and authoritative course/Evidence owner. Course QA, Study Agent, practice, reviews and flashcards retain their existing paths.

Opt in with the existing Tutor ASGI factory and `TUTOR_ENABLED=true AGENT_LLM_MODE=mock TUTOR_ENGINE=light`. The default engine remains P8. This candidate is not deployed and installs no real provider. The default Mock explicitly labels itself as a workflow example; it does not provide real teaching. Authored acceptance replies are confined to `eval/phase1d-lightweight/mock_app.py`.

Each turn performs at most two deterministic authority searches (current-question and initial/recent-topic retrieval hints, each at most 500 characters), re-READs all observed IDs and makes **at most one generation request**. The complete current question and complete dialogue are passed separately; retrieval hints are not the learner context. The simple response is `{outcome, text, focus}`: explanation or one targeted guiding question, inline citations, and a short literal learner phrase only for Socratic mode. No model tool planning, source-span blocks, calculator, automatic reviewer or repair loop is used.

A session permits six submitted turns and six model calls, 384,000 conservative reservation units total. A turn retains P8's 64,000-unit cap, 1,200 output-token reserve, 20-second deadline, 1,600-character answer and four-citation limit. Reservation units count complete UTF-8 serialized request/schema bytes plus output reserve; they are **not provider token usage or dollar charges**. Rejected, cancelled and unknown requests do not refund reservations. Oversized context/output fails explicitly without trimming, repair, retry or an additional model call. The prompt asks the model to state missing requested parts and ask to split an oversized task; semantics still need evaluation.

All learner questions and published replies in the six-turn session are retained verbatim, including explicit failed/unpublished turn status. No rolling summary silently drops earlier premises. Course excerpts can be incomplete: the unchanged Java authority returns at most 1,200 characters per Evidence item. The prompt states this boundary. The UI retains source text and original timeline navigation. Retrieval is not proof of whole-course coverage.

Supported answers must cite IDs observed **this turn**, pass authoritative re-READ and match the generation snapshot. Prior history cannot authorize citations. Verbatim-only extraction and a Socratic reply without a literal, included learner focus are rejected. These are limited mechanical checks: a paraphrase can still be wrong, a focused question can still be unhelpful, and a valid citation can fail to support its claim. Completeness, correctness and citation entailment are not automatically certified.

The original store's ownership/revision fences, idempotent keys, advisory executor lock, durable pre-send reservation, received-response checkpoint, cancellation and deletion purge are reused. A received response can resume without another generation; an unresolved reservation fails closed. Raw responses and valid usage remain in the private journal even if publication is cancelled or rejected. Public failed turns never expose drafts.

The additive session migration tags old sessions `engine=p8`, preserving their IDs and limits. Lightweight IDs, LIST/GET and worker discovery are engine-isolated. Matching updated workers/store must be used together; do not run an older, engine-unaware worker against a database containing light sessions. Disabling light hides its sessions from P8 without deleting them.

A future real adapter must enforce output/wire limits, zero retries and an audited dollar reservation/settlement policy with a fresh frozen identity and fresh one-time authorization. No real adapter or paid admission is enabled here. Phase 0 GitHub CI remains **PENDING**. See [Phase 1-D evidence](../eval/phase1d-lightweight/REPORT.md); Mock mechanism acceptance never establishes real-model teaching quality.
