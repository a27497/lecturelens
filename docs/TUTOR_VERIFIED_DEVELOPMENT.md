# Verified-publication Tutor development candidate

`p8-tutor-verified-v16-development` is an opt-in, Mock-only product factory:
`lecturelens_real_eval.tutor.verified_app:create_app`. It requires an exclusive
non-public `TUTOR_V16_DATABASE_URL`; never share a schema with earlier workers.
No default identity, old candidate, database schema or browser answer protocol is
changed. The additive Java `complete-v1` Evidence projection is reused unchanged.

The learner goal is a source-grounded explanation, bounded derivation or guiding
question. The model chooses contextual searches, observes authoritative evidence,
then selects source excerpts, a value expression or a hint act. Invalid provenance
or computation supplies a bounded correction observation; format and persistent
budgets retain their previous limits. Python/PostgreSQL store decisions, feedback
comparisons, accounting and the atomic final result. Unknown reserved calls stop
without resend; authority, deletion, cancellation and recovery fences still apply.

## Changed publication contract

- Course blocks are exact contiguous source excerpts, at most4 of300 characters.
  They cannot contain arbitrary newly generated assertions dressed as quotations.
- Derived blocks contain a literal source anchor and a bounded value expression.
  A pure interpreter computes rational arithmetic, bounded lists/tuples and range;
  it does not execute supplied course code. Expressions have at most120 characters,
  32 AST nodes and depth8, numbers have bounded decimal syntax and magnitude,
  powers are0..12, range has at most32 elements and result rendering at most160
  characters. No imports, arbitrary calls, names, comprehensions, attributes or I/O.
- Feedback compares up to two exact current learner spans (40 characters) with
  source spans (90). It does not invent correctness grades or mastery labels.
- Socratic output selects one source-bound intent: trace state, compare conditions,
  locate a rule, predict a step or check a boundary. The controller owns all visible
  question wording; free answer/feedback text is rejected in that mode. Required
  reflection after an earlier Socratic turn is also controller-owned. Course
  citations remain available to the learner and may contain solutions.

This is a narrower output contract than v15 free paraphrase, not a new semantic
entailment verifier. Exact excerpts can crop away conditions; an arithmetically
correct expression can use irrelevant premises; a fixed hint can be too generic.
Comparison-only feedback may not satisfy the requested correction. Those risks
remain subject to strict task/reference judgment. A residual misleading-crop
fixture intentionally still publishes and is not a quality pass. New real quality,
cost optimization, independent human agreement, SQL holdout, scaling and learning
effects are NOT_RUN.

All headers, source text, expressions, results, labels, separators and full
canonical IDs count toward unchanged1600/500 answer/evaluation limits and four
distinct IDs. Nothing is truncated to fit, mandatory reference points are not
removed, and insufficient representation/coverage is not credited as success.
Full completed-turn context, complete Evidence and v15 accounting are retained.
