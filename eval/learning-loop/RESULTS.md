真实取消检查发现旧成功反馈仍在数据库，但前端只显示最近一次执行，取消后没有入口访问旧反馈。新增按题的“最近反馈”选择器，支持查看旧作答版本和核对记录；运行中禁用切换，选择记录后从真实 API 刷新，核对意见绑定所选反馈。已验证同页取消和刷新后两种恢复路径。
