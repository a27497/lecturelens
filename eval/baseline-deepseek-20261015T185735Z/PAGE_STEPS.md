# 在管理页面绑定已保存的 DeepSeek

依据当前 `frontend/src/components/layout/AppHeader.vue`、`frontend/src/views/AdminModelManagementView.vue`、`frontend/src/api/systemModels.ts`。本轮只保存一次功能绑定，从版本 9 生成版本 10；没有编辑供应商、模型或密钥。

1. 使用管理员账号登录 LectureLens。点击顶部主导航的 **系统模型**，或直接打开 `/admin/settings/models`。旁边的 **模型管理** 是个人学习 Agent 设置页，本次操作入口是 **系统模型**。
2. 页面标题是 **系统模型**。必要时点击右侧 **刷新配置**，查看 **当前配置版本**。
3. 在 **功能绑定与有效配置** 区域找到 **字幕全文翻译** 行，对应功能键 `TRANSLATION_FULL_TEXT`。该行最后一列是 **新绑定**，下拉框的可访问名称是 **字幕全文翻译绑定**。
4. 把该下拉框从 **部署默认** 改成 **deepseek / deepseek-flash**。其中 `deepseek` 是本轮已保存供应商的名称；如果以后重命名，选项前半段会随名称变化。其他行保持原选择。
5. 点击表格下方 **保存功能绑定**。页面会显示新的 **当前配置版本**。再核对该行：**实际来源 / 版本** 为 **数据库绑定**和新版本，**模型 / 密钥** 为 `deepseek-flash` 与掩码，**最终请求地址** 为 `https://api.deepseek.com/chat/completions`。本轮新版本是 **10**。
6. 已有供应商和模型时，不需要进入下方 **供应商** 或 **模型** 编辑区，也不需要重新填 **API Key**。单独保存供应商或模型不会自动完成此功能绑定。
7. 如需自行做小请求测试，可在 **手动连通性测试** 找到对应模型，点击 **测试 JSON 连接**；这会真实调用供应商并可能产生费用。测试成功与 **保存功能绑定** 是两个独立动作，本轮基线没有额外点击该测试。
8. 在 **任务执行快照** 的 **任务 ID** 字段填入新任务 ID，点击 **查询快照**，可核对任务冻结的版本与全文翻译模型。旧任务继续使用原快照。

本轮结束后保留 DeepSeek 全文翻译绑定。个人页 `/settings/models` 的 Agent 决策 / 草稿复核没有被修改。
