## 预先约定的门槛

开发6/6、保留8/8均须在90秒内形成符合期望的反馈或拒答，并满足以下全部条件才标记该小样本反馈验收通过：

1. 针对**实际保存的作答**，引用的学生表述真实，既不捏造回答也不把不同措辞判错。
2. 每条建议/下一步由自己的课程引用支持；指出实际错误或遗漏，对正确作答不制造虚假纠错。
3. 课程外正确停止，不能借参考答案或模型常识声称课程已提供依据。
4. 不生成分数、掌握程度标签或长期记忆；更正记录不覆盖原始作答和模型反馈。
5. 无严重无据断言；报告全量失败、复核误拒绝/误接受、修订、全结果延迟和实际 provider usage。

逐题来源核查标明 AI 审阅，不充当盲评人工金标准；运行时复核不能代替独立评分。空白作答由接口拒绝，属于机制验证，不算模型的正确拒答。通过也仅放行本轮有界、实验性反馈能力，不放行自动评分或弱点记忆。

## 复现

使用独立 PostgreSQL 测试库，先运行Python/Java/前端检查，再避免与重型测试重叠：

```bash
AGENT_TEST_DATABASE_URL=postgresql://.../lecturelens_agent_pilot_test \
  uv run --directory agent-service python ../scripts/eval/evaluate-feedback.py \
  --runtime-config /private/runtime.json --owner-id SELECTED_OWNER \
  --cases ../eval/feedback-v1/development.json --output /private/new-trial-directory \
  --ledger /private/shared-feedback-call-ledger.jsonl --frozen-sha FROZEN_SOURCE_SHA256 \
  --call-limit 0
```

脚本只读选定用户原配置，在测试库建立随机隔离用户和独立加密连接，保存 Run 快照。完整结果落盘且 fsync 后，仅删除本轮 Session、Run、作答、反馈及 checkpoint；私有文件权限0600。异常中断时失败状态保留供恢复审查，不清空共享测试库。反馈默认 `STUDY_FEEDBACK_ENABLED=false`，显式隔离验收才打开。
