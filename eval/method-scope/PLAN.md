# 应用任务与课程方法对应

承接 [T 的失败](../field-support/RESULTS.md)，先修复范围对应，不进入自动后续练习或记忆。隔离 qwen3-max/max 沿用已有授权，总调用不限，每 Run 的预算与停止条件不变。

学习者需要以课程演示的方法完成新的小任务。模型搜索/补读后，独立复核根据观察原文记录最多两种方法的操作、输入、输出和精确原文片段（最终由Python按选定编号回填，不让模型转抄）；这些是可错的模型观察，不是事实证明。模型必须从当前观察中选方法生成通用应用题。新输入、同一操作中的错误可以迁移；新增操作或输出类别需要新课程依据。

方法选择、原文和后续范围判断写入原工具日志，恢复时复用。补读会刷新方法，重新搜索会使旧选择失效。缺失/伪造方法、未授权来源、预算耗尽或修复耗尽停止，不保存假产物；输出答案正确不抵消范围不支持。旧无方法记录允许历史回放。

验证顺序：独立 PostgreSQL 与协议测试；预标注的数学正确但超出教学范围反例及同法换值正例；T 等已消费目标回归。全部通过后才冻结新保留目标。失败、源码与输入哈希保留，不能把重复开发目标算作新验收。

本轮实现仅在 Python Agent 层；Java Evidence 权威、数据库所有权、线上配置不变。固定草稿诊断、完整自主执行、源文核查和独立人工验收分别报告。
