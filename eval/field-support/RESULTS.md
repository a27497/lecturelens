## 实现与边界

学习者仍通过模型选择搜索、补读、出题或拒答。Python 在原 Run 中增加可保存、可恢复的支持观察：

- 通用搜索先做候选不可见的课程覆盖检查，区分直接支持、已演示方法可迁移、缺失主题。该结果只是模型观察，不是事实权威。通用检索保留六个排名片段，为最多两个相邻片段留位；最多读取两个窗口，按时间补齐教学步骤，保持八段可见证据上限。
- 解释、概念题、应用题各自携带自己的来源，使用互不混用的字段内引用标识；验证后映射回原 Evidence ID。复核保存课程事实摘要、真实来源文本和完整短纠正意见，不能借另一字段的引用。
- 非计算题须记录预期答案及与原答案的匹配判断；不匹配必须拒绝。模型仍可同时给出错误答案和错误匹配判断，因此这不等于独立评分。已验证计算题先重建题目与计算证明，再隐藏确定答案，禁止语义复核覆盖确定计算。
- 明确要求“新字符串”时，若程序的全部多字符输入均已出现在观察原文中，会在原预算内要求换输入并重新计算。此检查只针对该明确要求；普通“新代码练习”不会仅因沿用字符串值而被拒绝。换输入本身不证明题目有教学价值或课程支持。

旧复核契约保留供历史回放。新契约单次输出上限从300改为900，持久预算按实际发送视图、schema和同一输出上限预留；**每 Run 6次模型、8次工具、64k保守预留、90秒、最多2份候选的限制不变**。取消、所有权、版本栅栏、幂等和 checkpoint 仍生效。来源绑定不合法、预算耗尽或修复耗尽均停止，不伪造完成。没有新增数据库所有权或 Java/前端功能。
