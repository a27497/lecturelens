Submit through the authenticated Java Tutor API with approved session request keys, then poll each turn to terminal and review it before the next submission. Use one worker and one in-flight request, no retries, no reviewer or remote embedding calls. Capture current scope, Evidence/index revision, exact selected excerpts, request hash, supplier ID/fingerprint, validated usage, reservation, settlement, reply and review result. The ledger uses peak rates even off-peak. After valid usage, it computes a local charge from cache hit, cache miss and completion tokens. The billed tokens may differ from the UTF-8 request proxy. Supplier-side model routing, rate changes, anomalous metering and unrelated use of the same supplier account can exceed a local estimate. There is no verified supplier hard cap. The separately approved operator must explicitly accept residual billing risk or obtain independently verified supplier-side protection. Reconfirm the model version, capabilities and current prices at that time. [Official pricing](https://api-docs.deepseek.com/quick_start/pricing/)

The previous 1,200 output reserve was a Mock request-size allowance. Use 4,096 on the experimental wire and in its separate request-size reservation so code, JSON escaping and CJK text have headroom. The 1,600-character publication cap and 64,000-unit request cap stay in force. DeepSeek's approximate English and Chinese character ratios give about 480 to 960 tokens for 1,600 typical characters before JSON and code overhead. Escaping, unusual Unicode and dense code can use more. [Token estimates](https://api-docs.deepseek.com/quick_start/token_usage/) The one-shot prompt gives an explicit JSON example and asks for a split when full teaching will not fit. An actual truncated or overlength response is a failed position and stops the experiment. Evaluate coverage and completeness separately. ## Admission and stop

- Use a fresh PostgreSQL database and isolated Java and Python instances, with only the frozen public materials and synthetic learner identity. Provision the singleton `tutor_flash_target` using `TARGET_SCHEMA` and `INSERT INTO tutor_flash_target DEFAULT VALUES RETURNING target_id`. Keep this database and its WAL durable across process restarts. Do not restore or clone a pre-consumption snapshot for reuse.
- A trusted operator separately installs a new private receipt matching the [Grant](../../agent-service/src/lecturelens_real_eval/tutor/flash_ledger.py) schema. Bind the database target ID, frozen dataset SHA, installed build digest, short validity window (at most 24 hours), model/version/price snapshot, request count and dollar budget. For each session bind the exact owner/course/revision, Java API creation key, approved Java READ text digests and ordered question/Socratic pairs. Verify every pair against the frozen dataset before granting. This is an operator-controlled file boundary. The gateway has no grant issuance or reset route.
- The dedicated `lecturelens_real_eval.tutor.flash_app:create_app` factory requires `TUTOR_FLASH_EXPERIMENT=enabled`, `AGENT_LLM_MODE=real`, `STUDY_AGENT_ENABLED=false`, the private receipt file and the isolated Agent/Java database configuration. The user supplies `TUTOR_FLASH_API_KEY` only in that process environment, after separate approval. Use no existing service key. Enable the Java Tutor gateway separately in the isolated Java process. The normal Python Tutor factory remains Mock-only. Offline test receipts have a different mode and the live factory rejects them.
- Stop on any unknown charge, transport/HTTP failure, blank/truncated/malformed result, protocol/citation failure, missing usage, metering overrun, model/fingerprint or price mismatch, expiry, version/source change, cancellation, budget exhaustion, or owner mismatch. Stop on a retrieval miss or known incorrect teaching if detected mid-run. Do not replace or resubmit a failed position. Reconcile an unknown reservation against supplier records outside the runtime before considering any later separately approved trial.
- Use the [frozen rubric](RUBRIC.md) for independent review. Model quality and supplier integration beyond the offline protocol simulation remain unmeasured until that separate trial.
