## 调用适配

对明确匹配的百炼 Qwen 配置显式发送 `enable_thinking=false`；只有一个工具时使用指定函数的 `tool_choice`，多个工具时使用 `auto`，由模型选择。仍要求 1–3 个合法工具调用，禁止把自然语言、截断输出或未提供的工具当成功，不做隐藏重试。

参考 [百炼 Function Calling](https://help.aliyun.com/zh/model-studio/qwen-function-calling) 与 [思考模式](https://help.aliyun.com/zh/model-studio/deep-thinking)。适配不应用到任意自定义域名、同名聚合服务或仅思考型号；其他服务保留原协议。鉴权、限流、网络、参数拒绝、输出截断等错误以脱敏错误码返回。
