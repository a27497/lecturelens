## 实现范围

- 对解释、第一题、第二题分别返回 `{issues, fix}`。拒绝的字段必须给出最多 120 字符的具体纠正意见；接受字段的 fix 为空。Python 汇总不超过 400 字符的私有反馈，让决策模型据此修订或补查证据。公开事件仍只有错误代码、来源和接受标志，不含答案或修订正文。
- 复核要求按题目原文核对答案和每条必需评分点，检查函数内部与调用处的全部打印，以及课程外新增断言。结构化复核并不保证这些检查在语义上正确执行。
- Python 代码格式与引用缺陷一次反馈，避免第一次只修格式、第二次才知道引用错误。清晰的普通多行代码可接受，不强制 Markdown 围栏；行内函数定义和字面反斜杠 n 的代码排版会触发格式修订。
- 显式标为 python/py 的代码块只做有界 AST 解析，提供语法有效性和顶层语句类型。每块最多 2,000 字符、每字段最多四块；不执行、导入或运行代码。语法错误可能是纠错题故意设置的，交给复核结合目标判断，不直接以语法失败拒绝。
- 页面保留题目和答案的换行、缩进。内容仍作为文本显示，不执行或解释为 HTML。
- 拒答使用独立提示和原有短 `issues` 契约，不携带练习检查顺序或代码观察，避免无关审查要求干扰课程外判断。

学习目标、模型可选的四个工具、权威 Evidence 检查、可持久化产物及失败终态不变。每题仍是 90 秒、6 次模型调用、8 次工具调用、64,000 保守 token 预留、最多两份候选；决策 900、复核 300 输出 tokens。一次工具格式纠正计入原预算。未引入自动评分、任意代码执行或模型切换。
