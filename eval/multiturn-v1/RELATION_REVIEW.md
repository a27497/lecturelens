## 本轮实现

[relation_probe.py](relation_probe.py) 让模型先返回相关来源关系与原句，再返回答案原句、缺口类型和支持判断。代码校验两个引文分别属于输入来源与答案，支持判断必须与缺口类型一致，禁止额外自由文本。这样避免把模型新编的解释作为纠正依据；引文存在性仍不证明语义支持。

契约分别处理以下情况：

- 定义之后的示例不自动限制定义，也不把示例属性推广到整个类别。
- `(A 或 B) → C` 可以支持 `B → C`，无需重述全部分支；`(A 且 B) → C` 不能直接支持 `A → C`。
- 一般描述命题与流程步骤指令分别判断；保留指令中的执行条件，不补不存在的流程分支。
- 前一步停止不代表后一步的资源条件成立；已观察到的顺序不证明未给出的排序指标。

原型仍只审一个完整答案与一段来源，没有接入多 Evidence 授权绑定、逐 Atomic 单元、修订反馈消费、账本复用或 Run 预算。它没有新增 Study 工具，也没有保存产品学习产物。
