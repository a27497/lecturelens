# Retrieval v2 prespecified protocol

Prepared before any scored retrieval, 2026-10-14. Phase A assets/code remain unchanged; production defaults remain Dense.

## Population and annotation

120 distinct queries across 6 MIT OCW courses, 18 lecture resources and 735 text Evidence (717 source extractions + 18 explicit partial Chinese adaptations). 96 answerable, 24 no-answer, 60 Chinese, 60 English, 24 genuinely cross-lecture questions whose required facts have distinct lecture/source locators. Source permission and attribution: SOURCES.md.

The course-level split was declared in split-plan.json before annotation: algorithms/linear/calculus/probability development (80 queries: 64 answerable, 16 no-answer); economics/quantum holdout (40 queries: 32 answerable, 8 no-answer). All languages, topics and paraphrases of a course stay in its partition. This does not prove the pretrained encoders never saw MIT materials. Dataset author sees source material and gold; encoders/ranker receive only the query and allowed corpus text.

Codex model-assisted authorship and source review, zero human annotators, no independent blinded adjudication. Sparse source-supported anchored qrels with required facts and alternative Evidence IDs; no-answer means unsupported by this frozen text snapshot, not absent from all lectures or unanswerable from outside knowledge. Annotation and Chinese factual adaptations can share systematic bias; confidence intervals do not model label error. Qrels are never revised after scores, failures never removed.

## Fixed methods and acquisition

Reuse Phase A's unchanged Ablations, BM25, production Retriever/chunker/LocalEmbedding, fixed quantized multilingual MiniLM and multilingual CE revision and weight hashes. Four strategies: dense, bm25_dense, hybrid_rrf, hybrid_rrf_ce. candidate_k=8, rerank_k=8, context_k=3, score fusion weights=.5/.5, RRF k=60, BM25 k1=1.2,b=.75. No fine-tuning, query expansion or adaptive labels. Same source-authorized corpus per method, isolated *_benchmark PostgreSQL database; owner/revision/allowlist/deletion checks retained. PDF Evidence has 0/0 non-media time placeholders and explicit page/normalized character positions, not synthetic media timestamps. Java ingestion/authority fidelity is not tested by this offline dataset.

Freeze config, corpus, cases, annotations, source attribution, code and dependencies before scored development. Development is a separate descriptive partition, not a tuning opportunity in this candidate. Then holdout executes once. The exclusive holdout-attempt.json reservation prevents retries, including crashes; partial/error trials remain. No method is selected or changed based on holdout. Each query/method is retrieved exactly once, with one latency observation; four-method order rotates by query. No latency repetition re-queries heldout questions. Shared fixed non-scored warmup uses only a development course. Acquisition never passes gold to retrieval or CE.

Index construction/model loading/warmup excluded from retrieval latency; query embedding, PG search, guards, BM25/fusion and CE included. Methods CPU-only, 2 encoder threads, same machine; do not overlap pytest/evaluations during acquisition. Save host load and test-process audit before every query. Existing unrelated system services are not stopped. Runtime errors preserve empty rank + failure type, counted in the denominator; an infrastructure failure is not a correct no-answer refusal.

## Metrics, failure buckets and uncertainty

Primary: holdout macro Evidence Coverage@3 (each required fact counts once, translations are alternatives). Report ID Recall@1/3/5/8, truncated MRR@1/3/5/8 and binary ID nDCG@1/3/5/8, fact coverage at all four K, and P50/P95 latency. Reuse Phase A definitions: ID recall counts the union of all alternative IDs, so duplication can penalize recall; nDCG may reward two translations of one fact. Fact coverage is primary to limit that artifact. CE reranks the same RRF top-8 set, so its @8 recall/coverage must equal RRF. Report all outcomes and sample counts; unanswerable questions have no relevance denominator and are excluded from recall/MRR/nDCG, never assigned perfect recall.

The four rankers have no answerability gate. On no-answer queries, count nonempty returned candidates as potential false evidence, not reader hallucination/refusal. Return rate is structurally high for forced-top-K rankers; add Wilson 95% binomial intervals (not a degenerate all-ones bootstrap) and separate retrieval errors. No reader, GAR, answer accuracy or complete Study Agent quality is assessed.

For every query/method with missing fact coverage at @3, a labelled hard negative at @3, a nonempty no-answer candidate list, or an execution error, retain a diagnostic failure row. Tags: not_recalled_in_candidates (missing required aspect at @8), ranked_below_context (missing @3 but every aspect represented @8), original_translation_duplicate (two equivalent IDs occupy @3 while a fact is missing), hard_negative_in_context, no_answer_candidate_returned, retrieval_error. Tags can overlap and are observations, not proven causal roots. Exclusive primary bucket precedence: error, no-answer, not-recalled, hard-negative, duplicate, low rank. Publish both counts and share of failures (tag shares can sum above 100%), with total-query denominators too.

Bootstrap draws=5,000, seed=1729 plus stable scope hash. Within each sampled course, resample whole question families with replacement, keeping all family members together. Families are lecture-specific four-query blocks, cross-lecture four-query blocks, and no-answer blocks; do not treat correlated questions as 120 independent trials. Report fixed-course family percentile 95% CIs and course-then-family hierarchical 95% CIs. Methods share exactly the same resampling weights for paired differences. Latency CIs use fixed-course family resampling of timed queries and Phase A's linear-interpolated quantiles.

Three primary paired Coverage@3 comparisons against Dense have Bonferroni familywise alpha=.05 (each interval at nominal 98.333%). Also publish exact two-sided course sign-flip p-values and Bonferroni-adjusted values; the symmetry/independent-course null is a sensitivity analysis, not a claim courses were randomly sampled. With only two heldout courses, the smallest two-sided exact p is .5, so this trial cannot establish a broadly significant course-level winner. Other metrics/language/cross-lecture intervals are exploratory 95% intervals, not multiplicity-adjusted claims. AI-label error, pretraining exposure and source-selection bias are outside every CI.

## Reproduction and preservation

One-command report reproduction reads the frozen rank/latency files without querying holdout again, deterministically regenerating bootstrap metrics and failures. Freeze verifier checks code/data/dependency hashes; reporting rejects duplicate/missing/foreign observations, changed splits, mismatched freezes or out-of-course hits. Each acquisition and report writes a new directory, never overwrites results. Corpus PDFs and weights remain outside Git; safe source snapshots, qrels, ranks, latency, summaries and digests are retained. Phase A vs v2 tables are descriptive comparisons on different questions/corpora, not a paired significance test.
