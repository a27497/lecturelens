# Retrieval v2：课程 Evidence 检索对照

已完成 **120 题、6 门 MIT OCW 课程、18 个讲次、735 条 Evidence** 的固定检索评测，覆盖 60 题中文、24 题无答案及 24 题真正跨讲取证。开发集 80 题、保留集 40 题按课程隔离；配置、语料、题目、代码和依赖在首次评分前冻结，保留集只采集一次。生产默认 Dense、Java 和既有 P0-1/P0-2 改动未改变，Phase A 冻结资产完整。

**CE 的保留集观测指标最高，但没有证据确认它普遍更好。** 保留集 Coverage@3 为 57.8125%，Dense 为 53.125%，差值 +4.6875 个百分点；同时校正的课程/题目族配对区间为 **[−15.625, +29.193] 个百分点**，包含 0，课程符号翻转 p=1。CE 的 P95 为 1120.31 ms，Dense 为 46.46 ms，约 24.11 倍。当前证据支持继续把 Dense 作为性能基线，CE 作为准确度/延迟权衡的实验候选；不据本轮改生产默认。

## 不确定性与权衡

预先指定主指标是保留集 Evidence Coverage@3，三个方法相对 Dense 的配对比较。5,000 次固定种子 bootstrap 保留同一题目族的相关性，四路使用相同抽样权重。报告固定课程的题目族 CI 与先课程、后题目族的分层 CI；三次主要比较用 Bonferroni 同时校正。其他指标、语言和跨讲切片为探索性分析，CI 不包含模型辅助标注误差、语料选择偏差或预训练泄漏。完整定义见 [PROTOCOL.md](PROTOCOL.md)。

|保留方案|Coverage@3，N=32|固定课程/题目族 CI95|课程/题目族 CI95|P50/P95 ms，N=40（各 CI95）|
|---|---:|---|---|---|
|Dense|53.125%|34.375–70.313%|31.250–70.313%|39.31 / 46.46（38.70–40.56 / 42.18–47.73）|
|BM25+Dense|48.438%|25.000–68.750%|25.000–68.750%|52.06 / 59.56（50.78–53.86 / 56.99–65.88）|
|RRF|51.563%|32.813–68.750%|29.648–68.750%|52.98 / 61.29（52.59–53.33 / 57.76–65.52）|
|RRF+CE|57.813%|48.438–68.750%|34.375–73.438%|662.01 / 1120.31（620.40–728.96 / 945.67–1663.85）|

CE−Dense 的固定课程配对区间为 −9.375 至 +23.438 个百分点；课程/题目族区间更宽（均为三个比较的同时校正区间）。两个保留课程方向不同：经济学 Coverage 46.875%→43.750%，量子物理 59.375%→71.875%，各 N=16 可回答题。只有两门保留课，双侧课程符号翻转最小可能 p=.5，本次 p=1；**不能把题目数 120 当作 120 个独立课程试验来宣称显著胜出。**

中文可回答题 N=48，总体 Coverage@3 为 Dense 40.625%、BM25+Dense 33.333%、RRF 37.500%、CE 51.042%；英文 N=48，分别 59.375%、60.417%、61.458%、59.375%。因此 CE 的整体观测增益主要与中文表现相符，尚不能泛化到所有语言或课程。

跨讲 N=24，Coverage@3 分别 33.333%、33.333%、35.417%、41.667%。这一切片每课程只有一个跨讲题族，固定课程/题目族 bootstrap 会退化为零宽度区间：**它不表示推广不确定性为零**，该切片只使用非退化的课程分层区间解释（CE 27.083–56.250%）。跨讲耗时的固定题族区间也仅条件于这些已测题，不描述未来查询或时间噪声；主保留/总体的耗时区间非退化。重复性不是低不确定性的替代品。
